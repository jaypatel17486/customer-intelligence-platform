# 📌 Overview

The Customer Churn Prediction API is a production-style machine learning application that predicts whether a customer is likely to churn based on demographic, contract, and billing information.

The project demonstrates the complete machine learning lifecycle including data preprocessing, feature engineering, model training, evaluation, REST API deployment using FastAPI, and Docker containerization.
